<objective>
Produce the rate data that 08-03's consumption path reads: a CRON_SECRET-gated cron route that batch-fetches HKD prices from CoinMarketCap and merge-writes them to Redis on a daily schedule — dependency-free, key-safe, and gracefully degrading.

Three pieces:
1. `fetchCryptoRates.ts` — a single native-fetch CMC client using id-based lookup (avoids the v2 symbol-collision array), mapping CMC id → locked shortName ticker via an explicit allowlist, rejecting non-positive/non-numeric prices at the boundary (D-03, ASVS V5, T-08-RATE).
2. `src/app/api/cron/refresh-rates/route.ts` — the official Vercel CRON_SECRET Bearer gate (reject-first 401, T-08-CRON), a graceful no-op when the CMC key is unset (D-02a), then fetch → `writeRateTableToRedis()` (merge, from 08-03).
3. `vercel.json` crons entry (daily).

Purpose: D-02 (CoinMarketCap cron), D-02a (credit-budget-aware, secret-only key, graceful degradation), D-04 (failure leaves last-known table untouched).
Output: the fetch client, the cron route, its Wave-0 test, and the vercel.json schedule.
</objective>
